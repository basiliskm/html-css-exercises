# HTML & CSS Exercises

Ασκήσεις HTML & CSS από το Coding Factory 10 (AUEB): δομή HTML, links & images, lists & tables, βασικό styling, typography και Flexbox.

## Περιεχόμενα

- `chapter1` – HTML intro, links & images, lists & tables, CSS styling, typography, Flexbox
- `html-xalvantzistaxi` – Παρουσιαστικό website για την εταιρεία Λάμπρος Χαλβαντζής ΤΑΞΙ
- `html-gadgetWRLD` – E-shop για την εταιρεία GadgetWRLD

## Εκτέλεση

Ανοίξτε το `index.html` του κάθε φακέλου στον browser (ή με Live Server στο VS Code).
